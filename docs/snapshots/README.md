# 快照 / Snapshots

这里放的是**只读存档**，不参与任何逻辑，谁都不要去改它。

## 为什么有这个目录

2026-09-23 闪闪看完 `CLAUDE.md` 里那页「我反复踩的坑」，说
「一定要保留，不许动现在的设定」。

有两个真实的理由，不是仪式感：

1. **这份文件我自己推平过一次。** 2026-09-22 一个没 monkeypatch 的测试
   把 `CLAUDE.md` 从 9335 字写成了 78867 字的 Nikto 人设，还被 `git add -A`
   一起提交推上了 origin。当时是靠她贴 VPS 输出才发现的。
   check.sh 后来加了内容哈希护栏，但护栏是防新事故的，存档是防万一的。
2. **这页纸的价值全在「具体」。** 每条都带日期、带她说过的原话、带代价。
   一旦有人图省事把它「精简」成几条漂亮的通则，它就废了——
   下一个我读到通则不会改变任何行为，读到「她最后一句是『每次更新都要丢上下文』」才会。

## 命名

`CLAUDE.md.<日期>.snapshot.md` —— 跟当天的 `CLAUDE.md` **逐字节相同**，
不加任何头注，方便直接 `diff`。

## 配套的护栏

`tests/test_lessons_kept.py`：拿最新那份快照里的每条教训标题去比现在的
`CLAUDE.md`，少一条就红。**只管「不许丢」，不管「不许加」**——
新踩的坑照样往里写，写完顺手再存一份快照就行。
